【專案說明】
本網站為單頁式長條型網頁，使用 HTML / CSS / JavaScript 製作，
不使用 React、Vue 等前端框架，可直接部署於一般主機環境。

--------------------------------------------------

【檔案結構說明】

index.html
- 網站主頁
- 主要內容與結構都在此檔案

css/
- 網站樣式檔（已編譯完成）

js/
- 網站互動功能（輪播、動畫、彈出視窗）

image/
- 圖片資源資料夾
- 可直接替換圖片檔案（建議尺寸不變）

【第三方套件說明】

本網站使用以下第三方套件，皆透過 CDN 載入：
- Bootstrap 5.3.3
- Swiper 11
- animate.css
- Splitting.js
- WOW.js
- Bootstrap Icons

網站正常運作需可連線至外部 CDN。
如未來需改為離線或內網環境，需將套件下載至本地使用。

--------------------------------------------------

【如何修改內容】

1. 修改文字內容
- 直接開啟 index.html
- 可搜尋 section 註解快速找到對應區塊

2. 更換圖片
- 將 image/ 內的圖片替換成同檔名檔案

--------------------------------------------------

【部署方式】

1. 將整個資料夾上傳至主機
2. 確認 index.html 位於網站根目錄
3. 直接開啟 index.html 即可瀏覽

※ 不需安裝任何套件或執行編譯指令

--------------------------------------------------

【注意事項】

- css 與 js 已為最終版本，修改前請確認需求
- 若需調整版型或動畫，建議由前端工程師處理
- 本專案未使用框架，維護彈性高
